## App Purpose

This native Android app helps users distinguish between genuine life hacks and internet urban myths through a flashcard quiz.



## Features

1. Welcome screen with Start button

2. Flashcard questions with Hack/Myth buttons + feedback

3. Score screen with personalized feedback + Review button

4. Uses ViewBinding and Intent to pass data between Activities



## GitHub Actions

Automated builds are configured using GitHub Actions to compile the app on every push.
